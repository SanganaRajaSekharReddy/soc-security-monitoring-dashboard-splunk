# 🔐 SOC Security Monitoring Dashboard Using Splunk

## 📌 Project Overview

This is my beginner-level **SOC Security Monitoring Dashboard** built using **Splunk**.

The purpose of this project is to monitor and analyze security login events using Splunk and SPL queries.

## 📊 Dashboard Features

* Total Security Events
* Successful Logins
* Failed Logins
* Login Activity Over Time
* Login Attempts by Username
* Failed Logins by Source IP

## 🛠️ Tools & Technologies

* Splunk
* SPL (Search Processing Language)
* SIEM
* Log Analysis
* Security Monitoring

## 🔍 What I Practiced

* Searching and analyzing security logs
* Creating SPL queries
* Monitoring successful and failed login events
* Analyzing usernames and source IP addresses
* Creating security dashboards
* Identifying suspicious login activity
